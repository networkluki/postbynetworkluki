# Post by networkluki

En liten, beroendefri blogg byggd med Python och WSGI. Sajten innehåller separata
delar för idéer och tips, blogginlägg samt en ändringslogg.

## Kör lokalt

```bash
python app.py
```

Öppna sedan <http://localhost:8000>.

## Testa

```bash
python -m unittest discover -s tests -v
```
