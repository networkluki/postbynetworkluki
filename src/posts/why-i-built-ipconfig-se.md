[ipconfig.se](https://ipconfig.se/) is my tool for quick checks of IP and network information. There I can see the public IP address the service sees, run DNS lookups and inspect information about the HTTP request.

The idea came out of my work with network programming. When I write and test code, I often need to quickly get the IP address and other details about the connection. I wanted to gather that in one easily accessible place.

I also wanted to be able to use the information in my own programs. The idea is that mobile apps and extensions for Chrome and Firefox should be able to fetch IP and connection information from ipconfig.se and use it for things like diagnostics and troubleshooting.

What appeals to me is the simplicity: building a small tool that solves a recurring need and can be used in more projects.

A need → A tool → More uses.

For me, ipconfig.se is part of the work of understanding, developing and troubleshooting network features.
