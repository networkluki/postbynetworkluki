[BitosX](https://bitosx.se) is my own password manager for collecting and managing login credentials in an encrypted vault. The project includes both a [desktop app](https://github.com/networkluki/bitosx/blob/6b42ce71d1f0a329d575bda81a8b157c210dc891/README.md) and a [web vault](https://github.com/networkluki/bitosx-manager/blob/main/README.md).

The idea came a few months ago when I was trying out other solutions. I like security and started thinking: why not build my own password manager and understand how all the parts work together?

I started writing BitosX as a test build. Over time the project grew, more features were added, and it developed into a full-fledged password manager. Curiosity became a project I wanted to keep developing.

What appeals to me most is having greater control over the code, how the data is handled and how the protection is built. I can examine the details, shape the whole and decide for myself how the solution should evolve.

With that control comes responsibility. The security needs to be proven through tests, review and continuous improvement.

Curiosity → Test build → Development → BitosX.

For me, BitosX brings together what I enjoy: programming, understanding systems and working with security.
